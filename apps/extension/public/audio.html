Provenance Lens

Check an audio file

Check one original audio file or an explicit short segment from a video URL. Lens checks supported OpenAI SynthID signals through your configured API backend.

The selected range must be whole seconds and 1–60 seconds long. Only the extracted audio segment is checked; the video and its frames are not analyzed.

Supported files must contain valid duration metadata and be no longer than 60 seconds or larger than 4 MiB. Raw PCM without a self describing header is rejected.

The backend sends the file to the documented OpenAI Content Provenance API. Successful normalized results may be retained in the authenticated server cache and bounded local cache; the audio bytes are not stored there or in history.

Audio checks use API mode only. Switch to API mode and acknowledge its privacy disclosure in Settings.
