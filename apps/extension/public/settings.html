Settings

API connection

Website review needs no backend. For API mode, enter a backend you control and its client access token. The OpenAI API key must stay on that backend. The client token is stored locally to authenticate API requests.

Use HTTPS for remote servers. HTTP is accepted only for loopback development.

A bundled connection is active. Public builds never include one.

API mode requires an exact-origin browser permission for the backend you configure.

Extension access

One click asks the browser to allow selected-image retrieval on all HTTP and HTTPS sites and exact selected-file downloads for Website mode, the API manual fallback or the Google SynthID handoff. The browser confirmation is required, and the extension still checks images only after your direct action.

Grant one site instead

For narrower access, grant only the exact image-host origin below. Existing grants are never removed when another request is denied.

Every other setting is in the Lens palette: click the toolbar button, then choose Settings.

Lens does not scan pages automatically. Verification starts only after you pick an image. Website review mode keeps the result on OpenAI’s site; API mode sends the exact file to your configured backend.
