Provenance Lens

Settings

Verification mode

Website mode downloads the exact selected image file and opens OpenAI Verify for you to upload and review manually. Lens never automates, submits to, or scrapes that website.

API mode sends the exact selected image or audio file to your configured verification backend for an automatic result. The backend and a valid OpenAI API key are required; the API key stays on the backend and is never stored in this extension.

API connection

Website review needs no backend. For API mode, enter a backend you control and its client access token. The OpenAI API key must stay on that backend.

Use HTTPS for remote servers. HTTP is accepted only for loopback development.

A bundled connection is active. Public builds never include one.

API mode requires an exact-origin browser permission for the backend you configure.

Privacy and history

Website mode writes no Lens result, history record, or cache entry. API mode can store only normalized results, check time, hostname, optional title, signal details, and exact-byte digests. Image bytes, cookies, full URLs, and keys are not stored in Lens history or caches. The client token is stored locally to authenticate API requests; the OpenAI API key is never stored in this extension.

Fallbacks

Disabled by default. A screenshot can remove metadata or weaken provenance signals, so its result can be less reliable.

Website review mode is the normal manual path: a successfully retrieved selected file is downloaded and OpenAI Verify is opened for your review. This extension never automates that website.

Extension access

One click asks the browser to allow selected-image retrieval on all HTTP and HTTPS sites and exact selected-file downloads for Website mode or the API manual fallback. The browser confirmation is required, and the extension still checks images only after your direct action.

Grant one site instead

For narrower access, grant only the exact image-host origin below. Existing grants are never removed when another request is denied.
